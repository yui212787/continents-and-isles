# Continents and Isles (大陆与群岛)

A Minecraft NeoForge 1.21.1 world generation mod that generates a single vast supercontinent surrounded by scattered islands.

一个 Minecraft NeoForge 1.21.1 世界生成模组，生成单一超大陆与外围群岛。

## Features (功能特性)

- **Supercontinent (超大陆)** — A single massive continent (configurable radius, default ~4250 blocks) with natural coastlines and beaches
- **Six sectors (六大扇区)** — The continent is divided into sectors with distinct themes: Snowy Plains (雪原), Mountains (山脉), Jungle (丛林), Savanna (热带草原), Desert (沙漠), and Archipelago (群岛)
- **WiFi-shaped mountain sector (Wifi 形山脉扇区)** — Concentric arcs of ridges with valleys between them, taller toward the surrounding ring mountains
- **Ring mountain belt (环山带)** — Encircles the whole continent, with random ore veins (diamond, gold, redstone, iron, copper, coal, lapis) of varying sizes
- **Three great lakes (三大湖泊)** — East Lake (island lake), Mountain Lake (deep lake, 50% Tianchi ring effect), and a random sector lake (biome lake)
- **Archipelago sector (群岛扇区)** — Inner sea with scattered islands, one mushroom island at center, ocean monument with a 300-block deep-ocean reserve
- **Guaranteed structures (必生结构)** — Desert temple in desert sector, woodland mansion, witch hut in swamp lakes, ocean monument
- **Fully configurable (完全可配置)** — Continent radius, sector biomes, secondary biomes, lake generation toggle, and more via config file
- **Modded biome support (模组群系支持)** — Mixes in biomes from other mods at ~12% probability when installed

## Requirements (运行要求)

- Minecraft 1.21.1
- NeoForge 21.1.x

## Installation (安装)

1. Install NeoForge 21.1.x for Minecraft 1.21.1
2. Place the `continents_and_isles-x.x.x.jar` into your `.minecraft/mods` folder
3. Launch the game and select the **"Continents and Isles"** world preset when creating a new world
